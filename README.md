# ONE-DNA™ Landing Page

Website voor ONE-DNA™ - Het mono-materiaal kunstgras dat volledig recyclebaar is.

## Over ONE-DNA™

ONE-DNA™ is een revolutionair kunstgras dat volledig is gemaakt van één materiaal (polyethyleen), waardoor het 100% recyclebaar is tot hoogwaardige nieuwe producten. Dit in tegenstelling tot conventioneel kunstgras dat uit meerdere materialen bestaat.

## Project Structuur

```
ONE-DNA/
├── index.html      # Hoofdpagina
├── css/
│   └── style.css   # Styling
├── assets/
│   └── images/     # Afbeeldingen
└── README.md
```

## Lokaal Ontwikkelen

Open `index.html` in een browser of gebruik een lokale server:

```bash
# Met Python
python -m http.server 8000

# Met Node.js (npx)
npx serve
```
